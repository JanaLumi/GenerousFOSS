The core premise here is generosity, kindness and resilience in design: space as an active element, progressive disclosure for complexity, and legibility as accessibility.

### Phase 1: Spatial & Ergonomic Hierarchy
 * Target Sizing (Fitts's Law): Primary interactive elements (buttons, toggles, inputs) must have a minimum touch/click target of 48 \times 48\text{ px} on touch screens and adequate padding on desktop. Bigger is structurally superior to smaller because it reduces cognitive friction and motor-control precision demands.
 * Generous Whitespace (Negative Space): Double standard margins between distinct UI blocks. Space is not "empty territory to fill"; it is the structural boundary that lets the eye parse relationships without reading fatigue.
 * Visual Grouping: Elements that belong together must sit within the same visual container or proximity threshold, utilising whitespace to separate groups rather than harsh borders or lines.
### Phase 2: Progressive Disclosure & Optionality
 * Opt-In Complexity: Keep the default interface minimal. Move advanced configuration, secondary tools, and power-user features into collapsible menus, drawers, or explicit settings toggles.
 * Contextual Reveal: Do not display every possible action upfront. Show tools only when relevant to the current user state or active object (e.g., hover states, selection menus).
 * Reducing Cognitive Load: Every persistent element on screen demands parsing energy. If a feature is used by less than 20% of users daily, it belongs behind a secondary action layer.
### Phase 3: Typography & Universal Legibility
 * Sans-Serif Baseline: Prioritise clean, human-designed sans-serif fonts (or rounded variants) over serif typefaces. Serifs introduce ornamental strokes that create visual noise, particularly for non-Latin script readers or multilingual interfaces where character density varies.
 * Scalable Typography: Ensure font sizes scale cleanly with system accessibility settings without breaking layout boundaries or text wrapping.
 * Line Length & Height: Restrict text blocks to a comfortable reading measure (roughly 60–75 characters per line) with generous line-height (1.5\times minimum) to prevent optical crowding.
